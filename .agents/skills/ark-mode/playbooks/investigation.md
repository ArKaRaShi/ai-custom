# Investigation

Read-only: leave files and git history unchanged.

1. Restate the question in one line. Exit: the question, and what answer would settle it.
2. Locate the code or data. Exit: the file and line ranges or tables that hold the answer.
3. Run it when running is cheap, such as a query or a command. Exit: observed output, not a guess from reading.
4. Answer with the conclusion first, then the evidence. Mark anything not observed as `[INFERENCE]`.
5. Offer a follow-up change only after the answer, as a separate question.
