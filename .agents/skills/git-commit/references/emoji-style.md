# Emoji Commit Style

Use this reference only when the user requests emoji style or repository history establishes it.

Format the subject with one type-appropriate emoji after the colon:

```text
<type>(<scope>): <emoji> <imperative summary>
```

Choose the emoji by commit type:

| Type | Emoji | Purpose |
| --- | --- | --- |
| `feat` | ✨ | New feature |
| `fix` | 🐛 | Bug fix |
| `refactor` | ♻️ | Restructure without behavior change |
| `perf` | ⚡ | Performance improvement |
| `docs` | 📝 | Documentation |
| `test` | 🧪 | Tests |
| `chore` | 🔧 | Tooling, dependencies, maintenance |
| `ci` | 🤖 | CI/CD |
| `build` | 📦 | Build and packaging |
| `style` | 🎨 | Formatting |
| `revert` | ⏪ | Revert |
