Where login lives in a project

The code that decides how long a login lasts sits under src/auth/. A folder holds what is inside it and sits in exactly one parent folder, so a file's position tells you where to look.

The project layout is illustrative.

Think of nested drawers: each drawer holds files or smaller drawers, and nothing is in two drawers at once. Hover or focus routes or auth to find it in the tree.

Select a folder, then choose What this feeds to mark everything inside it. Select a file, then choose What feeds this to mark the folders above it.

tree app[app/] src[src/] server[server.ts] routes[routes/] login[login.ts] orders[orders.ts] auth[auth/] session[session.ts] token[token.ts] tests[tests/] login_test[login.test.ts]
The project has two folders: src holds the program and tests holds its checks. Inside src, routes holds one file per web address. login.ts receives the login request. Also inside src, auth holds the code that checks who the user is: token.ts checks a token and session.ts decides how long a login lasts. Beside src, tests holds login.test.ts, the check for the login behaviour.

Pick one and lock it in. The answer stays hidden until you do.
