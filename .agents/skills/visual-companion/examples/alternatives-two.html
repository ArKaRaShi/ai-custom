Which of these two replaces code, scrub and inspect?

The same screen, the same data, in both columns — and both are live: click a state in either column and its own inspector follows.

One dimension separates them: where the state control lives. Alt 1 keeps a transport below the content and names every surface. Alt 2 deletes the transport, turns the states themselves into the control, and folds the inspector into a row of chips.

Alt 1 — Console

recommended default

Every component gets a name strip and one action. The scrub stays a real transport: arrows, count, thin track.

Alt 1 as the library default; Alt 2 wherever the states are the whole story. Alt 1 keeps one control that works at any length and is a CSS change over elements you already ship.
