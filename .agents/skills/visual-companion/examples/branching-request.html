Follow a branching request

The API can answer from cache or queue work for a worker. A failed job can retry; a reply is not a dependency.

Select a node to explore its dependencies. Hover or focus a queue or worker to find it in the diagram.

flow client[Client] --> lb[Load balancer] --> api[API] api --> cache[Cache] api --> queue[Queue] queue -.-> worker[Worker] --> db[Database] worker -->|retry| queue worker --> @return api
The client reaches the API through the load balancer. The API checks the cache before asking for more work. On a miss, the API queues work for a worker. The worker reads the database; a failure can send the job back to the queue. The worker returns its result through the API to the client.
