How an order retries payment

Only a timeout retries by itself, in place. A decline stops the order in failed until the customer retries or gives up. Both retries lead back to charging, and every order ends in shipped or cancelled.

The order rules and counts are illustrative.

An order is always in exactly one state, and each arrow is an event that moves it. failed is not the end. A terminal state is joined to the end marker, here shipped and cancelled.
