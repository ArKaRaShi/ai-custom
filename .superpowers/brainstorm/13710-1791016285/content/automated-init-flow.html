How "ai-sync" is Initialized on Another Mac / PC

Zero manual copying: How a fresh workstation gets the global CLI in 1 command

The 1-Step Onboarding Flow on Any New Machine
1
Clone your private backup repo:
git clone https://github.com/ArKaRaShi/ai-custom.git ~/Disk/ai-custom
2
Run the 1-Line Setup Script:
~/Disk/ai-custom/setup.sh

The script is located directly inside the repo root. You just run it once.

3
What setup.sh does automatically (Behind the scenes):
  • Creates ~/.local/bin if missing.
  • Symlinks ~/Disk/ai-custom/.agents/skills/ai-sync/bin/ai-sync ➔ ~/.local/bin/ai-sync.
  • Runs ai-sync bootstrap --apply to restore all your skills, rules, and agents.
The Code: ~/Disk/ai-custom/setup.sh (Committed to Repo Root)
#!/usr/bin/env bash
set -e

REPO_DIR="$(cd "$(dirname "$0")" && pwd)"
BIN_SRC="$REPO_DIR/.agents/skills/ai-sync/bin/ai-sync"
BIN_DEST="$HOME/.local/bin/ai-sync"

# 1. Ensure ~/.local/bin exists
mkdir -p "$HOME/.local/bin"

# 2. Symlink the trampoline runner so 'ai-sync' works everywhere
chmod +x "$BIN_SRC"
ln -sf "$BIN_SRC" "$BIN_DEST"
echo "✔ Linked ai-sync to $BIN_DEST"

# 3. Bootstrap this machine's skills, rules, and agents
"$BIN_DEST" bootstrap --apply

echo "🎉 Workstation initialized! 'ai-sync' is now active globally."

The Self-Healing Hook (Even if you never ran setup.sh!)

If someone ever runs ai-sync directly via Bun (e.g. bun ~/Disk/ai-custom/.../cli.ts), the engine has a built-in check:
"Is ~/.local/bin/ai-sync present? If not, automatically create the symlink now!"
So the moment ai-sync runs anywhere by anyone, it auto-registers itself globally in ~/.local/bin/.
