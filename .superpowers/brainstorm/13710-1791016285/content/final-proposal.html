Complete CLI Command Reference
Command Scope & Safety Action Executed
sync status Read-only (Default) High-level automated preview of drift across skills, rules, agents, configs.
sync push [--apply] [--git] Preview by default Exports newer local items into backup repo. Optional --git commits & pushes.
sync pull [--apply] [--git] Preview by default Imports newer repo items to this machine. Optional --git pulls remote first.
sync resolve <item> --ours|--theirs Safety snapshot first Atomic resolution: backs up replaced version to ~/.config/ai-sync/backups/ then updates.
sync add <module> <item> Shared (Git manifest) Registers an item (e.g. sync add skill my-tool or sync add rule ts-no-any).
sync remove <module> <item> Shared (Git manifest) Unregisters an item from the shared policy (never deletes local files).
sync ignore <path> --local Local (This PC only) Protects local private files (e.g. config.yml) from being synced or overwritten.
sync list [--local|--shared] Inspection Displays active shared ecosystem items or machine-local exclusions.
sync init [repo] Setup Creates clean v3 manifest in backup repository.
sync bootstrap [--apply] Disaster Recovery Restores all skills, rules, agents, and installs external tools on a fresh PC.
