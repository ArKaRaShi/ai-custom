Universal Resource Versioning: Beyond Skills

How ai-sync v3 versions Rules, Agents, Hooks, and Configs alongside Skills

How Each Resource Type Determines Version & Freshness
Resource Module Path Example Version Source Hash Algorithm
1. Skills skills/deep-research/ SKILL.md frontmatter (e.g. version: 1.2.0) Merkle tree hash of folder
2. Rules rules/ts-no-any.md YAML frontmatter version: 1.1.0 (if present) or 0.0.0 SHA-256 of file
3. Agents agents/sonic.md YAML frontmatter version: 2.0.0 (if present) or 0.0.0 SHA-256 of file
4. Hooks hooks/guard-destructive.ts Code header comment (e.g. // v1.0.0) or 0.0.0 SHA-256 of file
5. Configs mcp.json, models.yml Pure content hash (semver not needed for configs) SHA-256 of file
