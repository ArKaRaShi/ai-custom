Radical Zero-Boilerplate (The "Just Works" Model)
3 Radical Simplifications:
  1. No more roots: Automatically maps ~/.agents/skills and ~/.omp/agent. Zero setup.
  2. No more manual track: Any directory with a SKILL.md is automatically recognized and synced.
  3. Unified sync verb: One smart command previews both incoming and outgoing changes.
✔ Zero setup: run sync in any repo and it works.
✔ Create a folder with SKILL.md → immediately tracked.
✔ 80% less code, 0% administrative overhead.
What Daily Life Looks Like with Radical ai-sync
$ sync
ai-sync [3 updates available]
  ▲ skill-framework  v2.1.0 (local) > v2.0.0 (repo)  → will export to repo
  ▼ deep-research    v1.0.0 (local) < v1.1.0 (repo)  → will import to local
  ✔ mentor           v1.0.0                          [in sync]
  ✖ data-closure     v1.0.0 == v1.0.0 (content diff) → conflict

Run sync --apply to transfer safe updates.
Run sync resolve data-closure --ours|--theirs for conflicts.
Push local updates:
sync push --apply
Pull remote updates:
sync pull --apply
Resolve conflict safely:
sync resolve <skill> --ours

The Radical Deletion List

  • DELETE `root add` and `root bind`: Skills always live in ~/.agents/skills, OMP always in ~/.omp/agent. Override only if needed in a tiny ~/.config/ai-sync/config.json.
  • DELETE `track` and `discover` for authored skills: If you write a skill folder with a SKILL.md, it is automatically tracked. No discovery command, no registration dance.
  • DELETE `migrate-v2` & text-merge logic: Clean slate.
