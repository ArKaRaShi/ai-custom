Shell Path Integration: How ai-sync Works in Terminal

Why ~/.local/bin/ai-sync works globally, and how setup.sh ensures it on new machines

On Your Current Mac Right Now: Already Configured in ~/.zshrc!

I checked your machine's shell configuration:

# In /Users/example/.zshrc at line 139:
export PATH="$HOME/.local/bin:$PATH"

✔ ~/.local/bin is already in your active $PATH! Any binary linked there is immediately callable from anywhere in your terminal.

What Happens on a Brand-New Mac / PC?

If you clone to a brand-new Mac that doesn't have ~/.local/bin in its $PATH yet:

# Inside ~/Disk/ai-custom/setup.sh:

# 1. Symlink the binary:
mkdir -p "$HOME/.local/bin"
ln -sf "$PWD/.agents/skills/ai-sync/bin/ai-sync" "$HOME/.local/bin/ai-sync"

# 2. Check if ~/.local/bin is in $PATH:
if [[ ":$PATH:" != *":$HOME/.local/bin:"* ]]; then
  SHELL_RC="$HOME/.zshrc"
  [ -n "$BASH_VERSION" ] && SHELL_RC="$HOME/.bashrc"
  echo 'export PATH="$HOME/.local/bin:$PATH"' >> "$SHELL_RC"
  echo "✔ Added ~/.local/bin to $SHELL_RC"
fi

Just like brew, rustup, or pnpm setup, it ensures ~/.local/bin is in your shell configuration automatically.
