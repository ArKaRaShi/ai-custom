Main Entry Metadata: How .ts and Other Files Version

Every resource has a "Main Entry" that can declare an optional version

The Universal "Main Entry" Parser

Instead of guessing, ai-sync inspects the Main Entry of each resource using industry-standard conventions:

1. Markdown Files (Skills, Rules, Agents)

Main entry: SKILL.md or the *.md file itself

---
name: guard-rule
version: "1.2.0"
---
2. TypeScript Files (Hooks, Extensions)

Main entry: Top of *.ts file (JSDoc or comment)

/**
 * @version 1.0.0
 */
// or simple: // @version 1.0.0
export function preTool() { ... }
3. Packaged Tools (Node / Bun extensions)

Main entry: package.json

{
  "name": "my-extension",
  "version": "2.1.0"
}
What If a File Has No Version? (Zero Friction)

You don't HAVE to write version numbers if you don't want to.

If a file or hook has no @version, version defaults to "0.0.0" and ai-sync falls back to SHA-256 content hashing.

  • If content is modified ➔ flags as modified drift
