Pattern 1: The Trampoline Runner (Deep-Dive)

How Homebrew, Cargo, and Rustup update themselves without breaking or crashing

The Two-Stage Architecture
STAGE 1: THE TRAMPOLINE WRAPPER

~/.local/bin/sync (or shell function)

• Tiny 15-line POSIX shell script
• Never changes (immutable)
• Runs in 2 milliseconds

Job: Check if backup repo has a newer version of ai-sync. If so, fast-copy it to local before TypeScript boots!
➔
STAGE 2: THE MAIN ENGINE

~/.agents/skills/ai-sync/scripts/cli.ts

• Heavy TypeScript / Bun engine
• Can change from v3 ➔ v4 ➔ v10 with breaking changes
• Always executed fresh

Job: Parse manifest, calculate Merkle tree hashes, preview status, and execute sync transfers.
Execution Timeline: What Happens When You Type "sync" on PC #2
1
0ms: You type sync in terminal

The shell invokes the lightweight trampoline runner at ~/.local/bin/sync.

2
2ms: Trampoline checks Git remote (if --git flag is present)

If you passed sync pull --git, the wrapper runs git pull in ~/Disk/ai-custom so the repo has the latest code from GitHub.

3
4ms: The Self-Update Check (The Magic Step!)

The trampoline compares timestamps: Is ~/Disk/ai-custom/.agents/skills/ai-sync newer than ~/.agents/skills/ai-sync?
If YES: It copies the new files over in 5ms. Now your machine has the new v3 engine on disk before Bun/Node even starts!

4
10ms: Execute the Engine (exec)

The trampoline executes exec bun ~/.agents/skills/ai-sync/scripts/cli.ts "$@". The fresh, upgraded v3 engine runs without any errors!

The Complete Code: ~/.local/bin/sync (Only 18 Lines!)
#!/usr/bin/env bash
set -e

REPO="${AI_CUSTOM_REPO:-$HOME/Disk/ai-custom}"
LOCAL_SKILL="${AI_SYNC_DIR:-$HOME/.agents/skills/ai-sync}"
REPO_SKILL="$REPO/.agents/skills/ai-sync"

# 1. Pull Git first if requested via --git
if [[ "$*" == *"--git"* && "$*" == *"pull"* ]]; then
  git -C "$REPO" pull --ff-only 2>/dev/null || true
fi

# 2. Self-Bootstrap: If repo has a newer ai-sync, update local BEFORE booting engine
if [ -d "$REPO_SKILL" ] && [ "$REPO_SKILL" -nt "$LOCAL_SKILL" ]; then
  mkdir -p "$(dirname "$LOCAL_SKILL")"
  cp -R "$REPO_SKILL/" "$LOCAL_SKILL/"
fi

# 3. Hand off to the freshly updated TypeScript engine
exec bun "$LOCAL_SKILL/scripts/cli.ts" "$@"

Why Pattern 1 is the Ultimate Long-Term Fix

  • Immune to Breaking Changes: You can completely rewrite the TypeScript engine, change the manifest format, or add new flags. The bash wrapper doesn't parse JSON or know anything about manifests — it just ensures the local files match the repo before launching.
  • Zero Runtime Lag: File timestamp check (-nt) takes 0.001 seconds.
  • Standard Practice: This is how brew works (brew.sh updates Homebrew before running Ruby), and how rustup updates the Rust compiler.
