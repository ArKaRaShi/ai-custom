All Available Commands by Phase

Phase 1: Setup & Machine Binding
Command Target File Modified What It Does
sync init [repo] .ai-sync/manifest.json (shared) Initializes clean v3 manifest in backup repository.
sync root add <id> --repo-root <path> .ai-sync/manifest.json (shared) Registers a shared root (e.g. omp or skills) in backup policy.
sync root bind <id> --local-root <path> ~/.config/ai-sync/locations.json (local) Binds the root ID to this machine's folder (e.g. ~/.agents/skills).
Phase 2: Tracking & Machine Exclusions
Command Target File Modified What It Does
sync track <skill> .ai-sync/manifest.json (shared) Registers an authored skill to be backed up and version-tracked.
sync track <skill> --external --install "<cmd>" .ai-sync/manifest.json (shared) Registers an external skill with installer command (files not copied).
sync untrack <skill> .ai-sync/manifest.json (shared) Removes skill from shared policy (safe: never deletes local files).
sync exclude add <root> <pattern> ~/.config/ai-sync/locations.json (local) Excludes path on this Mac only (e.g. omp /config.yml). Zero Git conflicts.
sync exclude list Reads locations.json Lists all active machine-local exclusions.
Phase 3: Automated Preview & Discovery
Command Output Displayed What It Does
sync status [repo] High-level skill version table Displays which skills are [▲ LOCAL NEWER], [▼ REPO NEWER], or [✔ IN SYNC].
sync diff [repo] [<skill>] Unified diffs Shows exact code/text differences between local and repo copies.
sync discover [repo] Unlisted skill candidates Scans local directory for newly created skills not yet tracked.
Phase 4: Sync Transfers (Safe-by-Default)
Command Default Behavior With --apply
sync push [repo] Safe preview of local skills to export Exports newer local skills into backup repo. (Optional: --git-push).
sync pull [repo] Safe preview of repo skills to import Imports newer repo skills into local machine. (Optional: --git-pull).
sync bootstrap [repo] Reports skills to restore & install Pulls all synced skills and runs external installer commands on fresh machine.
Phase 5: Conflict Resolution with Safety Snapshot
Command Safety Action Resolution Effect
sync resolve --ours <skill> Snapshots repo skill to backup dir Local version wins: overwrites repo version with local.
sync resolve --theirs <skill> Snapshots local skill to ~/.config/ai-sync/backups/ Repo version wins: overwrites local version with repo.
