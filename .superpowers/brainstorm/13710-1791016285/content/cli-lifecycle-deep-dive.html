ai-sync v3: Full CLI Command Lifecycle Deep-Dive

From Day 1 onboarding to daily synchronization, multi-PC privacy, and disaster recovery

The End-to-End Lifecycle
STAGE 1: Setup & First Machine Onboarding

Run once to initialize the backup repository and link your local directories.

# In your backup repository (e.g. ~/Disk/ai-custom):
$ sync init
✔ Initialized ai-sync v3 manifest in .ai-sync/manifest.json

# Verify default paths (or customize in ~/.config/ai-sync/locations.json):
$ sync status
ai-sync [ready · 0 items tracked]
  ├─ skills → ~/.agents/skills
  ├─ omp → ~/.omp/agent
  └─ status ✔ cleanly bound
STAGE 2: Adding Resources & Machine-Local Privacy

Declare what is shared across all PCs vs what stays private to this machine.

# Track an authored skill (files will sync to Git):
$ sync add skill deep-research
✔ Tracked authored skill 'deep-research'

# Track an external skill with installer (only install command synced):
$ sync add skill archify --external --install "npx -y skills add tt-a1i/archify -g"
✔ Tracked external skill 'archify'

# Track rules, subagents, or hooks:
$ sync add rule ts-no-any
$ sync add agent sonic

# PRIVACY: Ignore local model config on THIS Mac only:
$ sync ignore config.yml --local
✔ Excluded 'config.yml' on this machine only (stored in ~/.config/ai-sync/locations.json)
STAGE 3: The Daily Workflow (Automated Status & Sync)

Check differences across modules and sync with safe previews.

# 1. Inspect status (aggregates all modules automatically):
$ sync
ai-sync:status [2 updates available across 5 modules]
  [SKILLS]
    ▲ skill-framework v2.1.0 (local) > v2.0.0 (repo) [LOCAL NEWER → push]
    ✔ deep-research v1.0.0 [IN SYNC]
  [RULES]
    ▼ ts-no-any.md (local modified < repo commit) [REPO NEWER → pull]
  [CONFIGS]
    ⊘ config.yml (local excluded on this Mac) [SKIPPED]

# 2. Push local newer updates to backup repo + GitHub:
$ sync push --apply --git
✔ Exported 1 newer skill: skill-framework
✔ Committed and pushed to GitHub main.

# 3. Pull incoming updates from GitHub + backup repo:
$ sync pull --apply --git
✔ Pulled latest commits from GitHub.
✔ Imported 1 updated rule: ts-no-any.md
STAGE 4: Handling Divergence (Zero-Data-Loss Conflict Resolution)

When two machines edited the same skill at the same version without syncing first.

# Status flags divergence:
✖ CONFLICT: data-closure (both sides are v1.0.0 with different hashes)

# Option A: You want Local version to win:
$ sync resolve data-closure --ours
✔ Saved safety snapshot to ~/.config/ai-sync/backups/data-closure-20261003-1540/
✔ Overwrote repo copy with your local version.

# Option B: You want Repo version to win:
$ sync resolve data-closure --theirs
✔ Saved safety snapshot of your local version to ~/.config/ai-sync/backups/data-closure-20261003-1540/
✔ Overwrote local copy with repo version. (Zero code lost; restorable anytime!)
STAGE 5: Bootstrapping a Fresh Machine

Setting up a brand new Mac, PC, or Linux workstation in seconds.

# 1. Clone your private backup repo:
$ git clone https://github.com/ArKaRaShi/ai-custom.git ~/Disk/ai-custom

# 2. Run bootstrap:
$ sync bootstrap --apply
ai-sync:bootstrap [restoring full AI workspace]
  ✔ Restored 24 authored skills to ~/.agents/skills/
  ✔ Restored 16 coding rules to ~/.omp/agent/rules/
  ✔ Restored 6 subagents to ~/.omp/agent/agents/
  ✔ Restored hooks & MCP configuration
