Conflict Resolution Strategy: My Vote & Comparison

Comparing how ai-sync v3 should handle conflicting skill edits across machines

MY VOTE (RECOMMENDED)
Option B

Safety-Snapshot + Atomic Skill Winner

Automated backup + zero broken syntax

~/.config/ai-sync/backups/ai-sync-20261003-1530/
✔ 100% snapshot before any overwrite

Why this wins

  • Zero broken code: Never injects <<<<<<< conflict markers into tests or scripts.
  • Zero data loss: Overwritten side is immediately restorable from local backup snapshot.
  • Frictionless: Deterministic; resolve with simple sync pull --theirs <skill> or sync push --ours <skill>.

Trade-off

  • Whole skill moves together (you can't automatically merge half of file A and half of file B).
Option A

Strict Manual Prompt (Ours vs Theirs)

Halt on conflict and ask in terminal

⚠ Conflict in deep-research (v1.0.0 vs v1.0.0)
[1] Keep Local (ours) [2] Take Repo (theirs) [s] Skip

Pros

  • Explicit control: never overwrites without direct terminal approval.
  • Simple mental model.

Cons

  • Blocks automated background or batch syncs until a user types an answer.
Option C

Line-by-Line 3-Way Merge (The Old Way)

Text-level diff3 insertion

<<<<<<< ours
export function sync() { ... }
=======
export async function sync() { ... }
>>>>>>> theirs

Pros

  • Allows granular line-level blending within a single file.

Why I vote AGAINST this

  • Syntax disaster: Conflict markers break TypeScript builds and unit tests.
  • File mismatch: Merging file A while file B was deleted or renamed breaks the whole skill.
  • The root cause of why ai-sync feels confusing today.

Summary of Recommendation

Skills are cohesive software packages (a script, its tests, and its documentation form a unit). Treating them like isolated text files and injecting diff markers causes fragile runtime errors.

My recommendation: Treat skills as atomic units. Version bumps fast-forward automatically; true conflicts create a safety snapshot in ~/.config/ai-sync/backups/ so you never lose code, with clear --ours or --theirs override commands.
