1. Universal Target Architecture (Multi-Harness)
Git Backup Repo (.ai-sync/manifest.json)
repoRoot is relative to the Git repository:
{
  "version": 3,
  "targets": {
    "agents": {
      "repoRoot": ".agents",
      "skills": {
        "deep-research": { "origin": "authored" },
        "archify": { "origin": "external", "install": "..." }
      }
    },
    "omp": {
      "repoRoot": ".omp",
      "rules": true,
      "agents": true,
      "hooks": true,
      "configs": ["mcp.json", "models.yml"]
    },
    "cursor": {
      "repoRoot": ".cursor",
      "rules": true
    },
    "claude": {
      "repoRoot": ".claude",
      "configs": ["settings.json"]
    }
  }
}
Local Machine (~/.config/ai-sync/locations.json)
targets are relative to User Home (~):
{
  "version": 3,
  "targets": {
    "agents": "~/.agents",
    "omp": "~/.omp/agent",
    "cursor": "~/.cursor",
    "claude": "~/.claude"
  },
  "excludes": [
    "omp/config.yml",
    "claude/credentials.json"
  ]
}

/* Never in Git.
   Protects local models, tokens, and hardware differences. */
The Sync Bridge: <backup-repo>/${manifest.targets[id].repoRoot}  ⟷  ${locations.targets[id]} in user home.
2. The 5-Phase End-to-End Lifecycle
Phase 1: Setup
sync init
Phase 2: Policy & Privacy
add / ignore --local
Phase 3: Daily Preview
sync status
Phase 4: Sync Transfer
push & pull (--apply)
Phase 5: Safe Resolution
resolve --ours/--theirs
$ sync
ai-sync:status [2 updates available across 4 targets]
  [AGENTS]
    ▲ skill-framework  v2.1.0 > v2.0.0   [LOCAL NEWER → push]
    ✔ deep-research    v1.0.0           [IN SYNC]
  [OMP]
    ▼ rules/ts-no-any.md             [REPO NEWER → pull]
    ⊘ config.yml                     [SKIPPED (local Mac exclude)]
  [CURSOR]
    ✔ rules/*.mdc                    [IN SYNC]

Run sync push --apply --git to export local updates and push to GitHub.
Run sync pull --apply --git to import incoming updates from GitHub.
3. Complete 10-Command Suite
Command Target Modified Action Executed
sync status Read-only (Default) High-level automated preview of drift across all targets and modules.
sync push [--apply] [--git] Backup Repo / Git Exports newer local items into backup repo. Optional --git commits & pushes.
sync pull [--apply] [--git] Local User Home (~) Imports newer repo items to this workstation. Optional --git pulls remote first.
sync resolve <item> --ours|--theirs Safety snapshot first Atomic conflict resolution: creates safety backup in ~/.config/ai-sync/backups/ then applies winner.
sync add <target> <item> Shared Manifest (Git) Registers an item in shared policy (e.g. sync add agents/skills my-tool).
sync remove <target> <item> Shared Manifest (Git) Unregisters an item from shared policy (safe: never deletes local files).
sync ignore <target/path> --local Local locations.json Protects local private files (e.g. omp/config.yml) on this PC only. Zero Git conflicts.
sync list [--local|--shared] Inspection Displays active shared ecosystem items or machine-local exclusions.
sync init [repo] Setup Initializes clean v3 manifest in backup repository.
sync bootstrap [--apply] Disaster Recovery Restores all targets and installs external tools on a brand new workstation.
