Path Mapping: Git Backup Repo vs User Home (~)

Clarifying what repoRoot vs localRoot mean with exact real-world paths

GIT BACKUP REPO (repoRoot)

Inside ~/Disk/ai-custom

Relative to the Git repository root

~/Disk/ai-custom/
├── .agents/         ← repoRoot: ".agents"
│   └── skills/
├── .omp/            ← repoRoot: ".omp"
│   ├── rules/
│   ├── agents/
│   ├── hooks/
│   └── config.yml
└── .ai-sync/
    └── manifest.json
USER HOME (~) (localRoot)

Inside /Users/ponthep/ (~)

Relative to your user home directory (~)

~/
├── .agents/skills/    ← local: "~/.agents"
├── .omp/agent/        ← local: "~/.omp/agent"
│   ├── rules/
│   ├── agents/
│   ├── hooks/
│   └── config.yml
└── .config/ai-sync/
    └── locations.json
How the Transfer Works

repoRoot is relative to your Git repository:
repoRoot: ".omp" means ~/Disk/ai-custom/.omp/

locations.json defines where that target lives in your user home directory (~):
"omp": "~/.omp/agent" means /Users/ponthep/.omp/agent/

The Sync Bridge:
~/Disk/ai-custom/.omp/ (Git repo)  ⟷  ~/.omp/agent/ (Live Mac user home)
