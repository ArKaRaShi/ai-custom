The Unified v3 Lifecycle Flow
STEP 1: ONBOARDING
sync init [repo]
sync bind omp ~/.omp/agent
sync bind agents ~/.agents/skills

Sets up v3 manifest and binds machine-specific local directories.

STEP 2: LOCAL PRIVACY
sync exclude add omp /config.yml

Keeps machine-specific configs (like this Mac's models) out of Git completely.

STEP 3: DAILY PREVIEW
sync status [repo]

Calculates skill versions and tree hashes. Shows high-level drift without inspecting files.

STEP 4: SYNC TRANSFERS
sync push --apply [--git]
sync pull --apply [--git]

Exports newer local skills or imports newer repo skills. Optional --git syncs GitHub.

STEP 5: SAFE CONFLICTS
sync resolve --ours <skill>
sync resolve --theirs <skill>

Saves safety backup snapshot to ~/.config/ai-sync/backups/ then applies the winner.

What Gets Permanently Deleted (Dead Weight Removed)

  • migrate-v2 & legacy parsers: Drop all v1/v2 conversion functions and backward compatibility shims.
  • plainMergeFiles & diff3 text merging: Never insert <<<<<<< into code.
  • Redundant aliases: Remove scan, apply, backup, save, review, combine, restore.
  • Loose file tracking inside skills: Skills are tracked as atomic packages, not loose files.
